# Korea Sector Rotation Alert ( 작동 안 됨) =부재중

## 📋 필요 사항

### 🔗 KRX Open API 인증키

1. [KRX Data Portal 회원가입](https://openapi.krx.co.kr)[cite: 2]
2. 마이페이지 > API 이용현황 > API 신청[cite: 2]
3. 다음 API 승인 신청:[cite: 2]
   * ETF 일별매매정보[cite: 2]
   * 코스닥 일별매매정보 (선택)[cite: 2]
   * 유가증권 일별매매정보 (선택)[cite: 2]
